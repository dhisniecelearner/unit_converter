# Python Unit Converter

A simple menu-driven Unit Converter built using Python. It allows users to convert Length, Weight, and Temperature units.

## Features

* **Length Conversion**

  * Kilometres to Metres
  * Metres to Centimetres
  * Metres to Kilometres

* **Weight Conversion**

  * Kilograms to Grams
  * Grams to Kilograms
  * Kilograms to Pounds

* **Temperature Conversion**

  * Celsius to Fahrenheit
  * Fahrenheit to Celsius
  * Celsius to Kelvin

* Repeat conversions without restarting the program.

* Handles invalid menu and conversion choices.

## Concepts Used

* Python variables and data types
* `input()` and `print()`
* Conditional statements (`if-elif-else`)
* `while` loop
* Basic mathematical operations

## How to Run

1. Download `unit_converter.py`.
2. Open it using Python IDLE or any Python IDE.
3. Run the program.
4. Select a conversion category.
5. Enter the required values.
